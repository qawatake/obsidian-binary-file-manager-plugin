# Repository instructions

After making any change to this plugin, run `./build.sh` before handing the work back. The script builds the plugin and copies the deployable files into the testing vault.

The user has authorized creating commits for this repository. Commit completed work without requesting separate confirmation, using one commit for each discrete user-requested change.

For CLI-driven testing, use `/Applications/Obsidian.app/Contents/MacOS/obsidian` when the `obsidian` command is not on PATH. If its output warns that the Obsidian installer is out of date, update the installer before relying on CLI registration or plugin reload behavior.
